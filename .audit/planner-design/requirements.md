# Original review closure requirements

Original finding IDs match the assistant's full 16-item final review, not the separate explorer reports.

1. Runtime grid validity. Distinguish truth validation, observation/model consistency, operating-condition/hazard assessment and route validation. Specify owners, triggers, diagnostic outputs, consequences, and no inference from AC convergence to explanation.
2. Task refresh. Fix unchanged-hypotheses-means-same-tasks. Separate deterministic candidate/eligibility/covariance refresh, semantic planner LLM calls, and assignment/route solves. Baseline ranking changes after readings without changing H0.
3. Explained updates. Every creation, assessment, scope, prediction, urgency or retirement change must have stored LLM-generated latest measurement finding and causal update reason. Include before/after, reading/event IDs/timestamps, diagnostics, contrary evidence/uncertainty; distinguish urgency from confidence; atomically reject missing/stale explanations; batch and no-measurement cases explicit.
4. Physical predictions. Define hypothesis-conditioned electrical candidate model changes and tests, local/mechanical evidence and operating conditions, competing explanations and unidentifiability. No silent accepted topology update or hidden truth input.
5. Invalidation. Cover reading, stranding, ready, landing, belief/known topology, actual hidden switching, manual commands, reading exclusion, model/prior revisions, expiry and errors. Changing hidden truth cannot directly change public estimator.
6. Completion/actions. Remove global known-healthy rule from P-only DC. Separate reconstruction completion, voltage/current/circuit operating assessment and local fault investigation. Unsupported checks remain unknown; define inspection/repair/evidence thresholds before full network observability.
7. Bad data. Empty suspects does not mean pass when critical/untestable. Local detectability/critical sets, real redundancy separate from pseudo rows, normalized residual covariance, sensor/model/topology/parameter/epoch alternatives. No automatic asset fault or bad-sensor conclusion from residual.
8. Uncertainty. Distinguish conditional covariance and priors from model/parameter/AC/topology discrepancy. Bound/calibrate uncertainty and treat unsupported calibration explicitly. Noise distribution, reference scales/floors/correlations and zero-flow behavior defined. No false 95% guarantee. Test no-noise prior bias.
9. Electrical mapping/sensing. Specify circuit allocation for missing and mixed voltages, reduced admittance/base/reference models, transformer assumptions, conditional 28-reading scope. AC terminal P/Q/I differ by losses and shunts; declare terminal-equivalent synthetic sensing or local observation function with both-terminal truth.
10. Independent state axes. Separate energization, chargeability, fault suspicion and coverage. Qualified contradictory observations invalidate LIVE before LLM; not only UNKNOWN updated. Voltage/current/clearing meanings distinct, circuit specificity, risk policy and evidence lifetime explicit.
11. Transactions. Publish pinned consistent snapshot before notification. Source revisions guard operator interleaving. Validate whole proposal/routes before any mutations. Explanations/hypotheses/models/tasks/routes atomic. No stale Release or duplicate retry. Same-time/zero-duration semantics clear.
12. Lifecycle. Stable sites, independent attempts, immutable readings and metadata history; pending/reserved/measuring/completed/cancelled/failed. In-progress ownership/dwell locked once; repeat/confirmation possible with purpose; no-op hypothesis semantics clear.
13. Routes. Exact offset and circuit landing, independently recomputed budget/dwell; every airborne drone continuation; projections avoid sparse landing false infeasibility; stay-put, occupancy, evidence validity, four-hour deadline. No assumption object field proves feasibility.
14. Coverage. <=1km sampling for 0.5km footprint plus clipped boundaries. Actual interval union with gaps/overlap, detection probabilities/conditions; negative/inconclusive distinct; thermal excitation and intermittent motion addressed.
15. Objective. Explicit urgency meaning, no planner priority inflation, multiple hypothesis associations, canonical observation/coverage groups, repeats/correlation, no double reward or stale additive information gain, strict urgency or explicitly chosen utility policy.
16. Solver/scenario/evaluation. Valid repaired incumbent and independent same-score comparison; bounded construction/search, correct solver statuses, watchdog/fallback and replay limits. Candidate cap, exact tiny joint allocation checks, no 100-line guarantee. Horizon limitation and two-sortie benchmark. Distinct healthy benchmark brief and real incident demo with local faults/contradiction. Correct LINE_024 switching vs protection event. COMPONENT_07 source fallback SUBSTATION_03, bounded operating-point generation including generation/boundary exchanges, transformer/island checks. Paired seed observation-keyed noise, LLM replay, honest metrics. No stale obsolete sketches or claims elsewhere.

Acceptance is document-level specification completeness and consistency. The new application and its future tests are not implemented by this task.
