# 11: Generate tasks only for accepted diagnostic needs

**What to build:** Translate accepted causal questions into current measurement opportunities without broadening an incident into general flow reconstruction.

**Blocked by:** 10: Accept explained decisions atomically.

**Status:** ready-for-agent

- [ ] Each incident need states the causal uncertainty, alternatives distinguished and how possible results could change diagnosis or action; every diagnostic task retains that association.
- [ ] Deterministic refresh responds to relevant evidence, covariance, coverage, reservation, expiry and availability changes even when hypotheses are unchanged.
- [ ] Canonical electrical groups identify equivalent observations at different offsets; local sites preserve exact spatial identity.
- [ ] Repeat and confirmation attempts link prior evidence or diagnostics and state their purpose; unavailable covariance produces labelled diagnostic options without invented information gains.
- [ ] Reservations change only through accepted decisions, measuring attempts retain ownership, and replacement candidate sets never erase completed or failed histories.
- [ ] Retired needs lose unsupported unstarted attempts and route stops before incumbent comparison; shared tasks survive only with another active justification.
- [ ] H0 and general observability-gap tasks activate only in healthy_benchmark; incident flow gaps alone create no task.
- [ ] Operator previews explain task purpose, ownership, repeats, cancellation and unavailable work; regressions cover unchanged hypotheses and retired needs.
